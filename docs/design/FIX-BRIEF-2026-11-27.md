# neotodak.com: five visual fixes (brief for Codex)

Context: the live homepage was reviewed by a second AI agent in a real browser at 1280x757 (laptop). Five problems were reported. Fix them in this repo with the SMALLEST change that works. Do not redesign; keep the dark-cinematic identity, fonts, colours and all copy exactly as is, except where a fix below says otherwise.

Files you will most likely touch: `app/[locale]/portfolio.css`, `components/portfolio/Portfolio.tsx`. Touch nothing else. No new dependencies. Do not run git commit/push.

## Fixes
1. **Hero buttons below the fold.** "Explore my work" and "More about me" start at about y=761-815 px, so they are hidden at 1280x757. Tighten the hero (spacing, headline size or min-height) so both buttons are fully visible without scrolling at 1280x757 AND at 390x844 (phone). Headline stays big and strong.
2. **Portrait seam.** The portrait (neo.jpg, parallax) extends past the hero's bottom edge and its lighter rectangle cuts hard against the near-black page. Make the portrait fade or clip cleanly into the page background: no visible rectangular edge at any scroll position.
3. **Orphaned colon.** The card title "police sentri : RUSH" can wrap as "police sentri" / ": RUSH". It must never leave the colon at the start of a line (keep " :" glued to the previous word). Same for the work-page title. Do not change the visible text.
4. **NACA City section.** The caption says "Explore the city to look around" but there is deliberately NO link (commit 068e769 hid it because naca.neotodak.com has no public door). DO NOT add a link. Remove the "explore" invitation sentence from the caption in all locales, keep "A snapshot of the public map." Reduce the large empty gap (~330-380 px) above the section to a normal section gap. The tiny labels are baked into the image; leave the image alone.
5. **Sticky header bleed.** The header is 93% opaque with no blur, so bright content shows through behind the logo and nav while scrolling. Add a backdrop blur and a slightly more opaque background (keep a fallback for browsers without backdrop-filter).
